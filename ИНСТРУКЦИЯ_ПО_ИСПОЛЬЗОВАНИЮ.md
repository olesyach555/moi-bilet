## 🚀 БЫСТРЫЙ СТАРТ (10 минут)

### Шаг 1: Подготовка БД (2 минуты)

1. Откройте **SQL Server Management Studio**
2. Подключитесь к вашему SQL Server
3. Откройте файл `СоздатьБД_СкриптSQL.sql`
4. Нажмите **Execute** (или Ctrl+E)
5. Проверьте, что БД создана успешно (см. вывод в "Messages")

```sql
-- Проверка создания БД:
SELECT name FROM sys.databases WHERE name = 'УниверсальноеПриложение';
```

### Шаг 2: Создание проекта (3 минуты)

1. Откройте **Visual Studio 2019+**
2. **Создайте новый проект**:
   - Тип: **Windows Forms App (.NET Framework)**
   - Название: `УниверсальноеПриложение`
   - Framework: **.NET Framework 4.7.2+**

3. **Добавьте папки проекта**:
   ```
   Формы/
   БизнесЛогика/
   ДоступКДанным/
   ```

### Шаг 3: Добавление кода (5 минут)

1. **Скопируйте содержимое файлов** в соответствующие классы вашего проекта:
   - `Program.cs` → ваш Program.cs (замена)
   - `КодЧасть2_App.config.xml` → ваш App.config (замена)
   - `КодЧасть3_DataAccess.cs` → создать файл `ДоступКДанным.cs` в папке `ДоступКДанным/`
   - `КодЧасть4_MainForm.cs` → создать файл `ГлавнаяФорма.cs` в папке `Формы/`
   - `КодЧасть5_ObjectForm.cs` → создать файл `ФормаОбъекта.cs` в папке `Формы/`

2. **Обновите строку подключения** в `App.config`:
   ```xml
   <add name="СтрокаПодключения"
        connectionString="Server=ИМЯ_ВАШЕГО_СЕРВЕРА;Database=УниверсальноеПриложение;Integrated Security=true;" />
   ```

   Примеры:
   - **Локальный сервер**: `Server=.;` или `Server=(local);`
   - **Именованный экземпляр**: `Server=ИМЯПК\SQLEXPRESS;`
   - **Удалённый сервер**: `Server=192.168.1.100;`

### Шаг 4: Проектирование GUI (в Design Mode)

Для каждой формы создайте в Visual Studio Designer:

**ГлавнаяФорма (MainForm):**
```
┌─────────────────────────────┐
│ [Добавить] [Изменить] [Удал]│
│ [Поиск] [Печать]            │
├─────────────────────────────┤
│ DataGridView - таблица      │
│ (имя: таблицаДанных)        │
├─────────────────────────────┤
│ StatusStrip (имя: строкаСоостояния)
└─────────────────────────────┘
```

**ФормаОбъекта:**
```
┌─────────────────────────┐
│ Наименование: [TextBox] │
│ Описание: [TextBox]     │
│ Статус: [ComboBox]      │
│ Примечания: [TextBox]   │
│ [Сохранить] [Отмена]   │
└─────────────────────────┘
```

### Шаг 5: Компиляция и запуск

1. Нажмите **F6** для компиляции
2. Нажмите **F5** для запуска
3. Должно открыться главное окно приложения

## 📝 АДАПТАЦИЯ ПОД КОНКРЕТНУЮ ЗАДАЧУ

Для переделки шаблона под одну из 30 задач из файла (например, "Адвокатская деятельность"):

### Этап 1: Переименование таблиц

В файле `СоздатьБД_СкриптSQL.sql` найдите:

```sql
CREATE TABLE dbo.ОсновныеОбъекты (
```

Замените на:

```sql
CREATE TABLE dbo.Адвокаты (
```

И обновите все ссылки на эту таблицу в процедурах.

### Этап 2: Добавление специфичных полей

Добавьте в таблицу поля для "Адвокатской деятельности":

```sql
ALTER TABLE dbo.Адвокаты ADD
    Телефон NVARCHAR(20),
    Email NVARCHAR(100),
    Специализация NVARCHAR(255),
    НомерЛицензии NVARCHAR(100),
    ДатаПолученияЛицензии DATETIME;
```

### Этап 3: Создание справочных таблиц

Если нужны связанные сущности (например, "Специализации"):

```sql
CREATE TABLE dbo.Специализации (
    ИДентификатор INT PRIMARY KEY IDENTITY(1,1),
    Наименование NVARCHAR(100) NOT NULL UNIQUE,
    Описание NVARCHAR(500)
);

-- Добавьте поле-ссылку в основную таблицу:
ALTER TABLE dbo.Адвокаты ADD
    ИДСпециализации INT,
    CONSTRAINT FK_Специализации FOREIGN KEY (ИДСпециализации)
        REFERENCES dbo.Специализации(ИДентификатор);
```

### Этап 4: Обновление интерфейса

В файле `ГлавнаяФорма.cs`:
- Измените название окна: `this.Text = "Управление адвокатами";`
- В `ФормаОбъекта.cs` добавьте новые поля ввода для телефона, e-mail и т.д.

### Этап 5: Обновление процедур

Отредактируйте хранимые процедуры, чтобы учитывать новые поля:

```sql
CREATE PROCEDURE sp_ВставитьАдвоката
    @Наименование NVARCHAR(255),
    @Телефон NVARCHAR(20),
    @Email NVARCHAR(100),
    @Специализация NVARCHAR(255),
    @НомерЛицензии NVARCHAR(100),
    -- ... остальные параметры
AS
BEGIN
    INSERT INTO dbo.Адвокаты (Наименование, Телефон, Email, Специализация, НомерЛицензии, ...)
    VALUES (@Наименование, @Телефон, @Email, @Специализация, @НомерЛицензии, ...);
END;
```

## 🔧 РЕШЕНИЕ ТИПИЧНЫХ ПРОБЛЕМ

### ❌ Ошибка: "Не удается подключиться к БД"

**Решение:**
1. Проверьте, запущен ли SQL Server:
   ```
   Services.msc → SQL Server (MSSQLSERVER) → Статус: Running
   ```
2. Проверьте строку подключения в App.config
3. Используйте SQL Server Management Studio для тестирования подключения:
   ```
   File → Connect → введите имя сервера → Connect
   ```

### ❌ Ошибка: "Процедура 'sp_ПолучитьВсеОбъекты' не существует"

**Решение:**
1. Откройте SQL Server Management Studio
2. Выполните файл `СоздатьБД_СкриптSQL.sql` полностью
3. Проверьте, что процедуры созданы:
   ```sql
   SELECT * FROM sys.procedures WHERE schema_id = SCHEMA_ID('dbo');
   ```

### ❌ Ошибка: "Конфликт версий .NET Framework"

**Решение:**
1. Перейдите в **Project Properties** (правый клик на проекте)
2. **Application** → **Target framework**: выберите **.NET Framework 4.7.2+**
3. Пересоберите проект (Ctrl+Shift+B)

### ❌ DataGridView пуст (нет данных)

**Решение:**
1. Проверьте наличие данных в БД:
   ```sql
   SELECT COUNT(*) FROM dbo.ОсновныеОбъекты;
   ```
2. Добавьте данные вручную:
   ```sql
   INSERT INTO dbo.ОсновныеОбъекты (Наименование, Описание, Статус)
   VALUES (N'Тестовый объект', N'Описание', N'Активно');
   ```
